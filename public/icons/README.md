# Carpeta de íconos

Coloca aquí íconos adicionales del proyecto, por ejemplo:

- `favicon.ico` / `favicon.png` — Ícono de la pestaña del navegador.
- Íconos personalizados para tipos de activos (laptop, impresora, servidor,
  etc.) si en algún momento se desea reemplazar los íconos SVG genéricos
  que ya incluye la interfaz.

## Favicon

Para usar un favicon propio, agrega el archivo aquí (por ejemplo
`/icons/favicon.png`) y actualiza la etiqueta `<link rel="icon">` en
`index.html`:

```html
<link rel="icon" type="image/png" href="/icons/favicon.png" />
```
